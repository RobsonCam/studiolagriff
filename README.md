# Studio La Griff

Sistema de gestão do Studio La Griff (agenda, atendimentos, clientes, financeiro), publicado em https://studiolagriff.netlify.app.

- Site estático: publicado pela Netlify a partir da branch `main` (sem comando de build, pasta de publicação `.`).
- Dados: Supabase (`config.js` tem só o endereço e a chave pública *anon*).
- Desenvolvido por FX Mídia Social.
